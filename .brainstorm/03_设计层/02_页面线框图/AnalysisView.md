# Analysis View页面 - 线框图设计

## 📱 页面概述
**功能定位**: 二维表格同时展示多个提示词的结构化要素对比  
**核心目标**: 用户一眼看到所有选中提示词的核心要素，快速识别差异

## 🎯 设计要点说明

### 页面结构
1. **对比表格**: 核心区域，横轴是提示词，纵轴是五大要素
2. **横向滚动控制**: 支持最多8个提示词同时对比，超出屏幕时可滚动
3. **快速洞察**: 底部总结区域，提炼关键差异点
4. **操作区域**: 表格操作和下一步行动指引

### 横向滚动设计特点
- **滚动指示器**: ●●●○○○○○ 显示当前查看位置和总数
- **滚动按钮**: 左右箭头按钮支持快速导航
- **进度提示**: "3/8 个提示词" 明确显示对比进度
- **多种交互方式**: 鼠标拖拽、键盘箭头、点击按钮三种滚动方式
- **容量标注**: "可容纳最多8个提示词进行对比" 明确功能边界

### 表格设计特点
- **二维对比**: 同时展示多个提示词的所有要素，一目了然
- **展开控制**: 每行支持展开查看详细内容，避免信息过载
- **简洁展示**: 默认显示核心信息，复杂内容可按需展开
- **视觉编码**: 用图标和颜色区分不同要素类型
- **自适应布局**: 表格内容根据滚动位置动态调整显示

### 交互优化
- **智能折叠**: 默认显示关键信息，支持逐行展开详细内容
- **滚动记忆**: 系统记住用户滚动位置，切换页面后回到原位置
- **批量操作**: 支持选中多个提示词进行批量操作
- **快速导出**: 一键导出整个对比表格，包含滚动区域外的内容
- **上下文操作**: 表格内直接操作，无需跳转页面

### 信息层级
1. **基本信息**: 名称、评分、复杂度 - 表头展示
2. **核心要素**: 五大要素的简化展示 - 表格主体
3. **详细内容**: 完整内容通过展开查看 - 按需显示
4. **关键洞察**: 差异总结和适用场景 - 底部辅助

### 用户价值
- **效率提升**: 无需逐个切换，一次性查看所有对比信息
- **扩展性强**: 支持最多8个提示词对比，满足复杂决策需求
- **决策支持**: 快速洞察区域直接提供选择建议
- **操作简化**: 减少页面跳转，在当前页完成大部分操作
- **信息完整**: 既有概览又有详情，满足不同层次需求
- **交互友好**: 多种滚动方式，适应不同用户习惯

这个改版实现了从"逐个分析"到"横向滚动并排对比"的体验升级，用户可以在同一屏幕内高效对比多个提示词设计方案，大大提升了分析效率和决策质量。
