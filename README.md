# Prompt Comparison

A project for comparing prompt designs from mainstream open source repositories.

## Purpose

Analyze and compare prompting strategies used across different open source projects to identify effective patterns and best practices.

## Contents

- **RooCodeInc/**: Example repository containing Roo Code VSCode extension
- **output/**: Analysis results and comparison data

## Usage

Examine prompt implementations in the included repositories to understand different approaches to:
- System prompts
- User instruction patterns  
- Context management
- Tool integration
